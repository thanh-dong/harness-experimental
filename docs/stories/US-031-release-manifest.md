# US-031 Machine-Readable Release Manifest

## Status

planned

## Lane

normal

## Product Contract

Each release publishes `manifest.json`: harness version, schema version,
per-platform binary names + sha256, bundle sha256, migration notes. A consumer
resolves "what do I download and is it intact" programmatically from one file.

Epic: E-shuttle-readiness. Unblocks Shuttle US-MH-01.

## Acceptance Criteria

- Manifest generated by the release workflow, never hand-edited.
- Checksums in manifest match published assets (CI-verified).
- Stable field names documented in scripts/README.md.

## Validation

| Layer | Expected proof |
| --- | --- |
| Unit | manifest generation from a dist dir |
| Integration | CI check: manifest ↔ assets consistency |

## Harness Delta

Release workflow addition; scripts/README.md documents the schema.
